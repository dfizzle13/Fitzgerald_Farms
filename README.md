# Fitzgerald Farms Website

A responsive single-page website based on the supplied Fitzgerald Farms homepage mockup.

## Included
- Responsive desktop and mobile navigation
- Hero, shop categories, farmers market dates, newsletter section, farm-video placeholder, farm story, and footer
- Accessible labels, responsive layouts, reduced-motion support, and descriptive image alt text
- Stock image links and a clearly marked YouTube embed replacement point

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
The workflow in `.github/workflows/pages.yml` deploys the site on pushes to `main`. In the repository, open **Settings → Pages** and make sure the publishing source is set to **GitHub Actions**. The first workflow run may need to finish before the site URL appears.

## Before launch
- Replace the placeholder market dates with the current season's schedule.
- Connect newsletter submissions to an email marketing provider or backend; the current form validates the email and shows a clear placeholder message but does not store addresses.
- Replace the stock image in the video section with a YouTube iframe when the farm video is ready.
- Replace stock photography and the text-based mark with approved farm images and brand artwork as available.
